# SCOPE project website

**Control-Ready Uncertainty for Trajectory Diffusion**

Live website: https://zackaxue.github.io/SCOPE-project-page/

This repository contains the public project page, figures, and videos.
The research code is marked **Coming soon** on the website.

## Publishing

GitHub Pages publishes the root of the `main` branch automatically.
All assets use relative paths so they work under `/SCOPE-project-page/`.

## Local preview

```sh
python3 scripts/serve.py
```

Open http://127.0.0.1:8000. The preview server supports video byte-range requests.
